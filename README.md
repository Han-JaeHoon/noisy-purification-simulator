# Noisy Entanglement Purification Simulator

Interactive browser simulator of round-by-round noisy entanglement purification
(Type 3, Type 4, 4Q, BBPSSW).

**Live site:** https://han-jaehoon.github.io/noisy-purification-simulator/

This repository contains only the compiled static website (`index.html`, `assets/`),
served by GitHub Pages from the `main` branch root. It runs entirely in the browser.
